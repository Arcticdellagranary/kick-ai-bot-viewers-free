## 💡 Was ist der Kick AI Bot?

Der **Kick AI Bot Viewers** ist eine KI-gestützte Anwendung, die das Zuschauerverhalten auf der Streaming-Plattform **Kick** simuliert. Mithilfe moderner KI-Modelle werden realistische Zuschauer-Sessions erzeugt, die sich wie echte Nutzer verhalten — mit variablen Watch-Zeiten, Interaktionen und Verbindungsmustern.

Im Gegensatz zu einfachen Bots, die nur HTTP-Anfragen senden, verwendet dieser Client **Verhaltens-KI**, um Muster zu erzeugen, die von echten Nutzern kaum zu unterscheiden sind.

### Kernkomponenten

| Komponente | Funktion |
|-----------|----------|
| 🤖 **KI-Modul** | Erzeugt realistisches Verhalten |
| 🌐 **Netzwerk-Layer** | Verwaltet HTTP/WebSocket-Verbindungen |
| 🎭 **Profil-Generator** | Simuliert Nutzer-Identitäten |
| 📊 **Dashboard** | Echtzeit-Überwachung |
| 🔄 **Proxy-Rotator** | IP-Wechsel für mehrere Sitzungen |
| 💾 **Session-Store** | Lokale Datenbank |

## ⚙️ Funktionsweise

```
┌──────────────────────────────────────────┐
│  1. KI generiert Nutzerprofile           │
├──────────────────────────────────────────┤
│  2. Profile starten Sitzungen            │
├──────────────────────────────────────────┤
│  3. Sitzungen verbinden mit Stream       │
├──────────────────────────────────────────┤
│  4. KI simuliert Verhalten (Sehen, Chat) │
├──────────────────────────────────────────┤
│  5. Kick zählt Zuschauer                 │
├──────────────────────────────────────────┤
│  6. Sitzungen enden nach variabler Zeit  │
└──────────────────────────────────────────┘
```

## 🛠️ Fehlerbehebung

| Problem | Ursache | Lösung |
|---------|---------|--------|
| ❌ Client startet nicht | Python fehlt | Python 3.11 installieren |
| ❌ Modulfehler | Abhängigkeiten | `pip install -r` |
| ❌ Sitzungen enden | Rate Limit | Intervall erhöhen |
| ❌ Stream erkennt nicht | Token ungültig | Neuen Token erzeugen |
| ❌ IP-Blockierung | Zu viele Verbindungen | Proxy verwenden |
| ❌ Dashboard öffnet nicht | Port belegt | Port ändern |
| ❌ Antivirus blockiert | Falschmeldung | Ausnahme hinzufügen |
| ❌ Hohe CPU | Zu viele Sitzungen | Anzahl reduzieren |

## ❓ Häufige Fragen

**Ist der Client kostenlos?**
Ja, Open Source unter MIT-Lizenz.

**Ist er sicher?**
Technisch ja, kann aber gegen Kick-ToS verstoßen.

**Brauche ich einen Proxy?**
Für viele Sitzungen ja. Für kleine Tests nicht.

**Wie viele Sitzungen möglich?**
50–100 ist realistisch, abhängig von Hardware.

**Funktioniert er unter Linux?**
Ja, plattformübergreifend.

**Gibt es eine Mobile-Version?**
Nein, nur Desktop.

**Was kostet die KI-Nutzung?**
OpenAI API separat abgerechnet (~0,01 €/1000 Anfragen).

**Wie viel RAM verbraucht er?**
~150 MB pro 10 Sitzungen mit KI.

**Brauche ich einen Kick-Account?**
Ja, um einen Kanal zu überwachen.

**Werde ich gesperrt?**
Möglich — vorsichtig und verantwortungsvoll nutzen.
